# 🎬 Video Subtitle Generator & Translator (v2)

**ابزار هوشمند تولید زیرنویس و ترجمه ویدیو با استفاده از هوش مصنوعی**

این نرم‌افزار یک ابزار دسکتاپ (ویندوز) است که به شما اجازه می‌دهد به صورت **آفلاین** و با استفاده از هوش مصنوعی، برای ویدیوهای خود زیرنویس تولید کنید و آن‌ها را به فارسی (یا انگلیسی) ترجمه کنید.

---

## ✨ ویژگی‌ها (Features)

*   ✅ **تولید خودکار زیرنویس:** تبدیل گفتار به نوشتار با دقت بالا با استفاده از مدل‌های **Vosk** (آفلاین).
*   ✅ **ترجمه همزمان:** قابلیت ترجمه زیرنویس تولید شده به فارسی (با Google Translate).
*   ✅ **ترجمه فایل SRT:** امکان وارد کردن فایل زیرنویس آماده و ترجمه آن به فارسی.
*   ✅ **رابط کاربری هوشمند:** پشتیبانی از Drag & Drop (کشیدن و رها کردن فایل).
*   ✅ **مدیریت مدل‌ها:** دانلود و مدیریت آسان مدل‌های هوش مصنوعی (Small, Medium) از داخل برنامه.
*   ✅ **سرعت بالا:** استفاده از FFmpeg بهینه شده برای استخراج سریع صدا.
*   ✅ **خروجی استاندارد:** دریافت فایل `.srt` استاندارد و هماهنگ با ویدیو.

---

## 🚀 نصب و اجرا (Installation)

### روش ۱: استفاده از فایل اجرایی (EXE) - **پیشنهادی** ⭐
این ساده‌ترین روش برای استفاده از برنامه است. در این حالت نیازی به نصب پایتون یا هیچ پیش‌نیاز دیگری ندارید؛ تمام کتابخانه‌ها و ابزارهای مورد نیاز (مثل FFmpeg) درون این فایل بسته‌بندی شده‌اند.

1.  به بخش [Releases](https://github.com/NASA60/VideoSubtitleGenerator/releases) در سمت راست همین صفحه بروید.
2.  آخرین نسخه فایل `VideoSubtitleGen_v2.exe` را دانلود کنید.
3.  فایل را اجرا کنید. 
    *(نکته: در اولین اجرا ممکن است باز شدن برنامه چند ثانیه طول بکشد چون فایل‌های داخلی در حال استخراج هستند).*

---

### روش ۲: اجرای سورس کد (برای توسعه‌دهندگان)

1.  مخزن را دانلود یا کلون کنید:
    ```bash
    git clone https://github.com/NASA60/VideoSubtitleGenerator.git
    cd VideoSubtitleGenerator
    ```

2.  کتابخانه‌های مورد نیاز را نصب کنید:
    ```bash
    pip install -r requirements.txt
    ```

3.  برنامه را اجرا کنید:
    ```bash
    python main.py
    ```

## 📖 راهنمای استفاده (User Guide)

برنامه دارای دو حالت اصلی است که از بالای صفحه قابل انتخاب است:

### ۱. حالت تولید زیرنویس (Generate from Video)
از این حالت برای ویدیوهای بدون زیرنویس استفاده کنید.
1.  گزینه **Generate from Video** را انتخاب کنید.
2.  فایل ویدیویی خود را داخل کادر بکشید (Drag & Drop).
3.  مدل هوش مصنوعی را انتخاب کنید (مدل `Medium` پیشنهاد می‌شود).
4.  زبان خروجی را روی **Persian (Farsi)** قرار دهید.
5.  دکمه **START GENERATION** را بزنید.
    *   *نتیجه:* یک فایل `.srt` کنار ویدیوی شما ساخته می‌شود.

### ۲. حالت ترجمه زیرنویس (Translate Existing SRT)
اگر از قبل فایل زیرنویس دارید و فقط می‌خواهید ترجمه شود:
1.  گزینه **Translate Existing SRT** را انتخاب کنید.
2.  فایل `.srt` خود را داخل کادر بکشید.
3.  دکمه **START TRANSLATION** را بزنید.
    *   *نتیجه:* فایل ترجمه شده با نام `_translated_fa.srt` ذخیره می‌شود.

## 🤖 درباره مدل‌ها (AI Models)

این برنامه از مدل‌های Vosk استفاده می‌کند که در پوشه `models` ذخیره می‌شوند.
*   **Small Model:** حجم کم (۵۰ مگابایت)، سرعت بسیار بالا، دقت معمولی.
*   **Medium Model:** حجم متوسط (۱۲۸ مگابایت)، دقت بسیار خوب (پیشنهاد ما).
*   **Large Model:** حجم بالا (۱.۸ گیگابایت)، بیشترین دقت (مناسب سیستم‌های قوی).

*نکته: مدل‌ها یکبار دانلود می‌شوند و دفعات بعدی به صورت آفلاین استفاده می‌شوند.*
